FreeSnitch 1.5 fixes the Network Monitor's byte counts and gives the app icon a dark look. If you use FreeSnitch 1.1.0 or newer, it updates itself. Coming from 1.0.0 or older, download the disk image once and replace the old copy; your rules and settings stay.

## Fixes

- **The Network Monitor counts bytes per connection again (#466).** Destinations under each app, the app totals, Top Domains and Top Countries all read "0 bytes" even while traffic was flowing; only Top Processes had real numbers. Each connection now gets the bytes macOS counted for its own socket, so all of them add up. `freesnitch summary` on the command line shows the same numbers and no longer counts a long-lived connection more than once. Counts can trail the real traffic by a few seconds. Insights still shows 0 bytes for now; that's #467.

## New

- **Dark, clear and tinted app icon (#471).** On macOS 26 and later the icon follows System Settings > Appearance > Icon & widget style: the same rings on a dark plate in dark mode, and proper clear and tinted looks. Settings > About shows the look macOS is using. Older macOS versions keep the light icon.
- **Hide the map in the Network Monitor (#473).** A map button next to the search field hides the map so the app list gets the whole width. Click it again to bring the map back. FreeSnitch remembers your choice.

Requires macOS 13 or later. One universal build for Apple Silicon and Intel, signed with a Developer ID and notarized by Apple.
