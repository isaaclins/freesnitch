FreeSnitch 1.4 speaks your language, starting with Russian. If you use FreeSnitch 1.1.0 or newer, it updates itself. Coming from 1.0.0 or older, download the disk image once and replace the old copy; your rules and settings stay.

## New

- **FreeSnitch in Russian (#459).** The whole app can now be translated, and Russian is the first language: the main window, the menu bar popover, connection alerts, settings and error messages. It follows your Mac's language, or pick it just for FreeSnitch under System Settings > General > Language & Region > Applications. Process names, host names, addresses, ports and your rules stay exactly as they are. The command line tool and the helper's logs stay in English. If something in the Russian text reads oddly, tell me in [#458](https://github.com/isaaclins/freesnitch/discussions/458) and I'll fix it. More languages are welcome; the text lives in `Resources/Localizable.xcstrings`.

## Fixes

- **The menu bar speed readout keeps one width (#460).** The upload and download speed next to the icon changed width with every update, so the icon and everything beside it slid back and forth. It now stays put.
- **DNS over HTTPS errors in your language (#464).** When Settings > DNS refuses an upstream address, the reason is now shown in the app's language instead of an English phrase inside a translated sentence.
- Counts read correctly in English too: Insights no longer says "1 destinations", and IP rules say "IP" instead of "Ip".

Requires macOS 13 or later. One universal build for Apple Silicon and Intel, signed with a Developer ID and notarized by Apple.
